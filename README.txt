SHRI SHRI ANDROID APP PROJECT

Package: com.shrishri.app
App name: Shri Shri
Minimum Android: 7.0 (API 24)

The full local Shri Shri video app is embedded in app/src/main/assets.
It supports the local UI, login/signup, video upload/file chooser, likes, comments,
subscriptions, shorts, channel, history and admin screens.

To generate an APK: open this folder in Android Studio and choose Build > Build APK(s).
